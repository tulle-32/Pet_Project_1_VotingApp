# Pet Project — Voting App на Kubernetes

Учебный проект: контейнеризированное multi-tier приложение (Vote → Redis → Worker → Postgres → Result), развёрнутое в Kubernetes.

## Стек
- Kubernetes (minikube)
- Docker-образы: dockersamples/examplevotingapp_vote, _worker, _result
- Redis, PostgreSQL
